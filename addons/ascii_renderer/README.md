# ASCII Renderer

Адаптация [AbstractBorderStudio/Ascii_Shader](https://github.com/AbstractBorderStudio/Ascii_Shader)
для Godot 4.7. Исходный коммит: `d076d632f145532393f0ab25ed2eeae682725c86`.
Автор исходного шейдера — Daniel Bologna, MIT (2024).
Атлас `textures/fill_ascii.png` взят из этого же репозитория и первоначально создан
Garrett Gunnell для [AcerolaFX](https://github.com/GarrettGunnell/AcerolaFX), MIT (2022).
Обе лицензии сохранены в `licenses/`.

Новый атлас `textures/ascii_16.svg` содержит оригинальные пиксельные рисунки проекта
и используется по умолчанию. Он создаётся из явных битовых шаблонов командой
`python tools/generate_ascii_atlas.py`; установленные шрифты и внешние пакеты не нужны.
Все 16 символов, включая пробел, имеют разную заполненность и отсортированы
по числу светлых пикселей: ` .:,-;~+=co%*#M@`.
Покрытие в клетках 8×8: 0, 1, 2, 3, 4, 5, 6, 9, 10, 11, 14, 15, 17, 20, 22, 25 пикселей.
Метаданные находятся в `textures/ascii_16.json`.

Изменения относительно оригинала:

- `canvas_item` на полноэкранном ColorRect вместо пространственной плоскости.
- Четыре выборки цвета на клетку, выбор символа по яркости.
- Размер клетки независим от исходного размера символа в атласе (8×8).
- Цветной и монохромный режимы, яркость, контраст и гамма.
- Сравнение: слева обычный кадр, справа ASCII.
- Выбор точного пикселя атласа без смешивания соседних символов.
- Переключение между исходным набором из 9 символов и новым набором из 16.

## Подключение

Добавьте `ascii_renderer.tscn` в свою игровую сцену. Эффект использует CanvasLayer 10.
Размещайте игровой интерфейс на CanvasLayer с большим номером, например 20.
Плагин редактора и C# не нужны.

```gdscript
$AsciiRenderer.enabled = true
$AsciiRenderer.colored = true
$AsciiRenderer.cell_size = 8
$AsciiRenderer.brightness = 1.0
$AsciiRenderer.character_set = AsciiRenderer.CharacterSet.EXTENDED_16
# Для исходного набора: AsciiRenderer.CharacterSet.ORIGINAL_9.
```

Параметры также доступны в инспекторе узла. Атлас — горизонтальная полоса квадратных
символов. При смене набора одновременно меняются текстура и число используемых элементов.
В исходном наборе используется 9 из 10 элементов; последний сплошной квадрат исключён.
В новом наборе используются все 16 элементов; сплошного квадрата в нём нет.
Атлас следует импортировать без сжатия с потерями и без mipmaps; фильтрация в шейдере nearest.

Это постобработка изображения: она не меняет геометрию, физику и игровые скрипты.
Выделение направленных ASCII-контуров и временная стабилизация пока не реализованы.
